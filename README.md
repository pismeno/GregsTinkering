## Greg's Tinkering
This is git repository of Greg's Tinkering. It is a mod that provides Tinker's Construct materials for GTCEu 1.12.2.
## Where to download?
you can download this modpack at CurseForge [here](https://www.curseforge.com/minecraft/mc-mods/gregs-tinkering).  
## Configuration
This mod is highly configurable. You can disable any material in the mods conflig, as well as other things.
